# MediaLab Downloader

برنامج تحميل لويندوز (Rust + Slint) مع إضافة للمتصفح.
A Windows download manager (Rust + Slint) with a browser extension.

## Build (GitHub Actions)
1. The complete source is stored directly in this repository.
2. Build locally on Windows using `BUILD.bat` or `build-windows.ps1`.
3. Optional secrets for signed updates and Firefox signing are documented in the build workflow when present.

## Extension
`extension/` – Chrome/Edge: open `chrome://extensions`, enable Developer mode, then choose Load unpacked.
